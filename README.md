# 丹丹 · 专属公考刷题库

> 💝 丹丹专属版 —— 由「公考刷题库」个性化定制而来，仅供个人学习使用。

在线地址：<https://fenggary.github.io/dandan-gongkao-tiku/>

访问口令请向版本所有者索取，未配置于本仓库中。

## 功能

- 课程章节
- 真题试卷（国考 + 广东省考/深圳）
- 专项练习
- 随机抽题
- 错题本
- 收藏题
- 学习记录
- 电脑 / 手机响应式使用
- 前端访问门禁

## 题库范围

| 模块 | 说明 |
|---|---|
| 国考行测 | 按年份/卷别按需加载 |
| 国考申论 | 公开资料整理 |
| 广东省考/深圳行测 | 广东、广州、深圳真题 |
| 广东省考/深圳申论 | 广东、广州、深圳真题 |
| 广东事业编 | 公基/职测/综应广东卷 |

> 已按个人需求裁剪：省考/事业编仅保留广东相关真题，其余省份与联考卷已移除。

## 使用方式

1. 打开在线地址。
2. 输入访问口令。
3. 选择国考、省考或事业编。
4. 选择科目，进入学习章节、专项练习或真题试卷。
5. 错题和收藏保存在当前浏览器中。

手机端可在浏览器菜单中选择"添加到主屏幕"。

## 个性化说明

本版本基于开源项目 [gongkao-tiku](https://github.com/linfukai186-arch/gongkao-tiku) 二次定制：

- 品牌名称替换为"丹丹 · 专属公考刷题库"，含专属页脚标识。
- 访问口令以加盐混淆形式校验，仓库中不含明文口令。
- 题库裁剪为"国考 + 广东真题"。

## 本地开发

```bash
python3 -m http.server 8765
# 打开 http://127.0.0.1:8765/
```

## 隐私与安全说明

页面访问门禁为前端实现，用于防路人级访问，**并非服务端安全认证**。如需真正私有，请使用私有仓库 + 私有 Pages（通常需付费方案）或 Cloudflare Access 等。

## 项目文件

- `index.html`：页面结构
- `style.css`：响应式样式（清淡配色）
- `app.js`：刷题、判分、错题、收藏、学习记录
- `bank.js`：题库目录和按需加载
- `course.js`：课程章节配置
- `lock.js`：前端访问门禁（加盐混淆校验）
- `data/<模块>/index.json`：试卷索引
- `data/<模块>/y<年份>.json`：按年份试卷数据
- `data/practice/<模块>.json`：练习题包
