## 功能

- 课程章节
- 真题试卷
- 专项练习
- 随机抽题
- 错题本
- 收藏题
- 学习记录
- 电脑 / 手机响应式使用
- 前端密码门禁（`yangdan666`）

| 省考行测 | ~21000 | 覆盖多省、联考 |
| 省考申论 | ~3400 | 公开资料整理 |

| 事业编综应 | ~1000 | 案例/实务/公文/作文 |

## 使用方式

1. 打开在线地址。
2. 输入访问密码：`yangdan666`。
3. 选择国考、省考或事业编。
4. 选择科目，进入学习章节、专项练习或真题试卷。
5. 错题和收藏保存在当前浏览器中。

手机端可在浏览器菜单中选择"添加到主屏幕"。

## 项目文件

- `index.html`：页面结构
- `style.css`：响应式样式
- `app.js`：刷题、判分、错题、收藏、学习记录
- `bank.js`：题库目录和按需加载
- `course.js`：课程章节配置
- `lock.js`：前端密码门禁（密码哈希）
- `data/<模块>/index.json`：试卷索引
- `data/<模块>/y<年份>.json`：按年份试卷数据
- `data/practice/<模块>.json`：练习题包
